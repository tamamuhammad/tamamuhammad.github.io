# Personal Web Portfolio

A responsive and interactive personal portfolio website built to showcase web development projects, technical skills, and professional experience. 

**Live Demo:** [tamamuhammad.github.io](https://tamam.my.id)

## ✨ Fitur Utama (Key Features)

* **Interactive User Interface:** Desain antarmuka yang modern dan responsif untuk berbagai ukuran layar (Desktop, Tablet, Mobile).
* **Light / Dark Mode Theme:** Dilengkapi dengan fitur peralihan tema terang dan gelap menggunakan manipulasi CSS presisi untuk kenyamanan visual pengguna.
* **Project Showcase:** Menampilkan galeri proyek terstruktur dengan deskripsi teknis.
* **Optimized Performance:** Dibangun dengan *best practices* penulisan struktur HTML dan CSS yang efisien.

## 💻 Teknologi yang Digunakan (Tech Stack)

* **HTML5:** Struktur semantik halaman web.
* **CSS3 & TailwindCSS:** *Styling*, tata letak (Flexbox/Grid), dan transisi tema (Light/Dark mode).
* **JavaScript (ES6):** Interaktivitas antarmuka dan logika *toggle* tema.
* **Git & GitHub:** Version control dan *hosting* (GitHub Pages).
